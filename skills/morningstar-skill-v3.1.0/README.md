# MorningStar Skill v3.1.0

Free public edition. The canonical skill is `SKILL.md`.

## What changed
- Consolidates the v3 six-engine architecture and governance safeguards.
- Restores the four-stage workflow: semantic decomposition; initial conditions and causal mapping; structural diagnosis and counterexample testing; synthesis and verification.
- Adds four quality gates for scope, evidence, logic, and calibration.
- Adds a deep-thinking and repeated-verification protocol designed to reduce hallucinations and errors without claiming infallibility.
- Retains AC-01 as a v2.1.0 compatibility reference. Its exact original wording remains pending authoritative source-text comparison; no equivalence is claimed yet.

## Install
Copy this folder's `SKILL.md` into the target agent's skill directory or follow that agent platform's current skill-install instructions.
