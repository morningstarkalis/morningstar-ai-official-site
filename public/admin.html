ADMIN · PRIVATE OPERATIONS

首次管理員初始化

只有在 Cloudflare Worker 已設定一次性 ADMIN_BOOTSTRAP_TOKEN 且尚無管理員時才能初始化。完成後請設定 ADMIN_TOTP_SECRET，再使用管理員登入。

管理員登入

登入只建立管理員 Session；查看控制台及每一項敏感操作，還需要輸入新的 6 位數 TOTP。未設定 MFA 時，管理 API 會拒絕操作。

產品狀態
